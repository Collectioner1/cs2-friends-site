# SORMOVO — сайт команды друзей по CS2

Статический сайт в тёмном киберспортивном стиле для команды друзей по Counter-Strike 2. Опубликован на GitHub Pages из ветки `main`, корень репозитория.

Сайт: https://collectioner1.github.io/cs2-friends-site/

## Разделы

- герой со статистикой команды и логотипом;
- состав из семи игроков с аватарками из Steam, ролями и реальными метриками;
- календарь еженедельных игр по средам до конца года;
- статистика семи игроков за последние 30 матчей, достижения и таблица лидеров;
- состав с показателями из этой сводки (K/D и процент побед).

## Технологии

Только HTML, CSS и ванильный JavaScript. Внешние библиотеки и шрифты не используются. Логотип в шапке — крупная буква S в собственном SVG (`assets/img/logo.svg`), в герое — изображение `assets/img/logotype.png`.

## Источники данных

Аватарки, ники и SteamID игроков — из публичных профилей Steam. K/D, процент побед, матчи, победы, убийства и смерти — из публичных профилей Leetify, привязанных к тем же SteamID (выборка «последние 30 матчей» на момент обновления). Роли и даты еженедельных игр заданы вручную. Steam Web API не предоставляет публичную историю матчей и статистику за период: `GetUserStatsForGame` возвращает только накопительные счётчики и требует личного ключа.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой статический сервер из корня папки, например:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

## Обновление данных

Основной контент находится в `index.html`: состав — в блоке `#team`, матчи — в `#matches`, статистика — в `#stats`. Цвета и адаптив настраиваются в `assets/css/style.css`, поведение меню — в `assets/js/main.js`.
