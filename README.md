# NEXUS — сайт команды друзей по CS2

Статический сайт в тёмном киберспортивном стиле для команды друзей по Counter-Strike 2. Опубликован на GitHub Pages из ветки `main`, корень репозитория.

Сайт: https://collectioner1.github.io/cs2-friends-site/

## Разделы

- герой с статистикой команды и блоком счёта;
- состав из пяти игроков с ролями и демонстрационными метриками;
- календарь матчей с переключением «Предстоящие / Результаты»;
- новости команды с раскрытием полного текста;
- карты и процент побед;
- демонстрационная форма набора в команду.

## Технологии

Только HTML, CSS и ванильный JavaScript. Внешние библиотеки и шрифты не используются. Иконка — собственный SVG (`assets/img/logo.svg`).

## Демо-данные

Ники игроков, результаты матчей, статистика, контакты Discord/Telegram и проценты побед вымышлены и нужны только для примера. Форма заявки ничего не отправляет: после отправки появляется уведомление. Кнопка «Приглашение» копирует демонстрационный текст.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой статический сервер из корня папки, например:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

## Обновление данных

Основной контент находится в `index.html`: состав — в блоке `#team`, матчи — в `#matches`, новости — в `#news`, карты — в `#maps`. Цвета и адаптив настраиваются в `assets/css/style.css`, поведение кнопок — в `assets/js/main.js`.
