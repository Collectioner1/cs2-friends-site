# SORMOVO — сайт команды друзей по CS2

Статический сайт в тёмном киберспортивном стиле для команды друзей по Counter-Strike 2. Опубликован на GitHub Pages из ветки `main`, корень репозитория.

Сайт: https://collectioner1.github.io/cs2-friends-site/

## Разделы

- герой со статистикой команды и логотипом;
- состав из четырёх игроков с аватарками из Steam, ролями и демонстрационными метриками;
- календарь еженедельных игр по средам до конца года;
- карты и процент побед.

## Технологии

Только HTML, CSS и ванильный JavaScript. Внешние библиотеки и шрифты не используются. Логотип в шапке — крупная буква S в собственном SVG (`assets/img/logo.svg`), в герое — изображение `assets/img/logotype.jpg`.

## Демо-данные

Аватарки и ники игроков взяты из публичных профилей Steam. Роли, даты еженедельных игр, статистика, контакты Discord/Telegram и проценты побед нужны только для примера.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой статический сервер из корня папки, например:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000/`.

## Обновление данных

Основной контент находится в `index.html`: состав — в блоке `#team`, матчи — в `#matches`, карты — в `#maps`. Цвета и адаптив настраиваются в `assets/css/style.css`, поведение меню — в `assets/js/main.js`.
